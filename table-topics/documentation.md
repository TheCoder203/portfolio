### Documentation

AstroPlatformer includes high-level comments that explain how gravity, collision, and scoring work. That kind of documentation is useful not just for this game, but for anyone reading code later to understand the design.

```javascript
//  AstroPlatformer - "Crater Falls"
//  HOW THE PLATFORM SYSTEM WORKS
//  Every 16ms the physics loop runs:
//  1. HORIZONTAL VELOCITY ...
//  7. SPIKE DEATH ...
```

In AstroPlatformer, this snippet shows how the topic appears in the actual game code and helps demonstrate the idea with a working example. In AstroPlatformer, the top-level comments document how gravity, platform collision, spikes, and win conditions work together, making the design easier to follow.
